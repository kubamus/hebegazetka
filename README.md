# Jak to działa

Aplikacja odczytuje dane z API hebe (w formacie json) i używa OCR. Eksportuje je do excela.

# Jak uruchomić

Utworzyć virtual environment i zainstalować wymagane zależności.
Uruchomić `python hebe.py`. Wynik w folderze `/outputs/`. Dwa pliki excel, do czarnego piątku i ta zwykła
